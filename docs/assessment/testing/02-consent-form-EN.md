# Consent to take part in a usability test

**Project:** QuoteDesk, a tool that helps freelancers prepare price offers
**Researcher:** Maria Glowacka, Robert Gordon University, module CM3026 Autonomous Coding

**What you will do:** set up the app with your own business details and prices, prepare one offer from a made up client message, and answer a few questions. It takes about 25 minutes.

**What is recorded:** the time each task takes, your answers to the questions and short written notes on what happens. Nothing is recorded on video or audio unless you agree below.

**How your data is used:** only for this university project. You are identified by a code (for example P1), never by name. Notes are stored privately; anonymous results may appear in the project report and video.

**Your rights:** taking part is voluntary. You can stop at any time and ask for your data to be deleted, without giving a reason.

**AI notice:** some features send the made up client message to Anthropic's Claude service. Please do not type any real client's details.
