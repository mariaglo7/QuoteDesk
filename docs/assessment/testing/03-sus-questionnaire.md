# System Usability Scale (SUS)

Standard questionnaire by John Brooke (1996). Answer each statement from 1 (strongly disagree) to 5 (strongly agree).

| # | English | Polski | 1 to 5 |
|---|---|---|---|
| 1 | I think that I would like to use this system frequently. | Myślę, że chciałabym lub chciałbym często korzystać z tej aplikacji. | |
| 2 | I found the system unnecessarily complex. | Aplikacja wydała mi się niepotrzebnie skomplikowana. | |
| 3 | I thought the system was easy to use. | Aplikacja była łatwa w użyciu. | |
| 4 | I think that I would need the support of a technical person to be able to use this system. | Potrzebowałabym lub potrzebowałbym pomocy osoby technicznej, żeby z niej korzystać. | |
| 5 | I found the various functions in this system were well integrated. | Funkcje aplikacji dobrze ze sobą współgrają. | |
| 6 | I thought there was too much inconsistency in this system. | W aplikacji było za dużo niespójności. | |
| 7 | I would imagine that most people would learn to use this system very quickly. | Myślę, że większość osób szybko nauczyłaby się z niej korzystać. | |
| 8 | I found the system very cumbersome to use. | Korzystanie z aplikacji było uciążliwe. | |
| 9 | I felt very confident using the system. | Czułam lub czułem się pewnie, korzystając z aplikacji. | |
| 10 | I needed to learn a lot of things before I could get going with this system. | Musiałam lub musiałem nauczyć się wielu rzeczy, zanim mogłam lub mogłem zacząć. | |

## Score

For odd items take the answer minus 1; for even items take 5 minus the answer. Add the ten values and multiply by 2.5. The result is 0 to 100; about 68 is average.
